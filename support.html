Support and frequently asked questions

Why are some results “Needs review”?

Many accessibility requirements cannot be decided by a program. For example, the app can see that an image has alternative text, but not whether the text describes the image well. In these cases the app reports “Needs review” instead of a pass: when it cannot be sure, it never tells you that everything is fine. Use the Manual Checks view to go through these items.

Why do my results differ from another validator?

Different tools interpret some rules in different ways, check different sets of conditions, and sometimes read the file differently. A known example: when a PDF has been edited and saved incrementally, it contains more than one revision of the same page. In one case we documented, veraPDF read a superseded revision of a page, while this app (through macOS) read the current one, so the two tools reported different results for the same file. If results differ, the explanation in the app tells you what was checked and where.

PDF Accessibility Checker implements a subset of the automatic PDF/UA rules, plus a few checks that other validators do not have. See how the app compares with PAC, veraPDF and Acrobat.

Can I check encrypted PDFs?

Yes, if macOS can open them. They cannot be fixed automatically, however: save the document again without security settings, then run the fix.

What happens with damaged files?

If a file’s index is damaged, macOS repairs it while reading and the app tells you so: the results then describe the repaired file, and other readers may see something different. If the internal structure is too damaged, the app cannot fix the file safely; export it again from the original document.

Why did the check stop on a very large file?

To keep the Mac responsive, the analysis stops after a time limit. This usually happens with files that contain very heavy images. Try again; if it happens again, the file may be damaged, or you can export a lighter version from the source document.

How do I restore my Pro purchase?

Open the Pro purchase screen in the app and choose Restore Purchases. Make sure you are signed in to the App Store with the same Apple Account you used for the purchase.

Does a clean result mean my PDF is legally compliant?

No. The app helps you find and fix many problems, but no automatic tool can certify conformance with a law or a standard. Manual review remains necessary.

How do I report a problem?

Write to Lagioni Apps Support at batesstamp.support@gmail.com. Please describe what you did, what you expected and what happened, and include the macOS version. Do not attach confidential documents.

PDF Accessibility Checker helps you check the accessibility of PDF files. It does not certify legal conformance with any law or standard.
