Informativa sulla privacy

Ultimo aggiornamento: 16 ottobre 2026

In breve

PDF Accessibility Checker non raccoglie, non conserva e non trasmette alcun dato personale. I tuoi file non lasciano mai il Mac.

I tuoi file

  • I file PDF sono analizzati localmente, sul tuo Mac, in un processo di supporto separato e isolato (sandbox).
  • Nessun file, nome di file, contenuto o risultato viene inviato altrove.
  • I file corretti sono salvati come nuovi file accanto agli originali; l’app non ne conserva copie.

Rete

L’app non si collega a internet, con un’unica eccezione: l’acquisto in-app di Pro (e il suo ripristino) passa dall’App Store di Apple. La transazione è gestita da Apple secondo la politica sulla privacy di Apple; lo sviluppatore non riceve alcuna informazione personale su di te.

Nessun account, nessuna statistica

  • Non ci sono account né accessi.
  • Non ci sono statistiche d’uso, pubblicità o tracciamenti di alcun tipo nell’app.

Questo sito

Questo sito non usa cookie, tracker, statistiche d’uso né risorse esterne come font o script caricati da altri server. È ospitato su GitHub Pages; come qualsiasi servizio di hosting, GitHub può trattare dati tecnici come gli indirizzi IP per fornire le pagine, come descritto nella dichiarazione sulla privacy di GitHub (in inglese).

Contatti

Per domande sulla privacy, scrivi a Lagioni Apps Support all’indirizzo batesstamp.support@gmail.com.

PDF Accessibility Checker aiuta a controllare l'accessibilità dei file PDF. Non certifica la conformità legale a nessuna norma o standard.
