How to use PDF Accessibility Checker

This guide walks you through a typical check, from opening a file to exporting a report.

1. Open one or more PDFs

Choose File > Open (Command-O) or drag PDF files onto the app window. In the free version the app checks one file at a time. With Pro you can drop several files or whole folders: the app checks them all and shows a summary for each file in the sidebar.

2. Read the summary

At the top of the window you see a short summary such as “12 errors in 4 categories”, followed by the number of errors, warnings and items to review, and the number of pages. The results use three levels:

  • Error – blocks some users;
  • Warning – makes the document harder to use or is very likely wrong;
  • Needs review – the app cannot be sure and asks you to look. It never reports a pass when it is not sure.

Automatic checks find many problems, not all of them. A clean result is not a certificate of legal conformance.

3. Select a problem

In the Problems view, select a problem in the list. The app shows:

  • what the problem means and who it affects, in plain language;
  • where it is: the location is highlighted on the page preview;
  • how to fix it in the original document, with instructions for Microsoft Word, Pages and Adobe InDesign;
  • a Fix button, if the app can fix the problem automatically (Pro).

4. Screen Reader tab

The Screen Reader view shows the text in the order of the tags, as a screen reader reads it: headings with their level, lists, tables and the alternative text of each image. Images without alternative text are clearly marked. Choose Read Aloud to hear the text.

5. Manual Checks tab

Some checks need a human judgement: whether the alternative text describes each image, whether the reading order is logical, whether text has enough contrast, whether color is the only way information is given. The Manual Checks view lists them; for alternative text, it shows the images one by one next to their descriptions. Items count as “needs review” until you answer.

6. Fix (Pro)

Choose Fix to apply the available automatic fixes: document language (proposed from the text), title and DisplayDocTitle, repair of invalid XMP metadata and removal of the author and document metadata. The result is saved as a new file, name-accessible.pdf, next to the original; the original is never overwritten. The new file is checked again automatically.

7. Export a report (Pro)

Choose Export Report to save the results as an accessible tagged PDF, to share with colleagues or clients, or as a CSV file to open in a spreadsheet.

8. Finder Quick Action (Pro)

You can check a PDF without opening the app first: right-click a PDF in the Finder and choose Quick Actions > Check Accessibility. If the action does not appear, enable it in System Settings > General > Login Items & Extensions > Finder (the exact wording can vary slightly between macOS versions).
